Daily Bridge Sync — Setup

One-time setup, then daily it's a single click while you're on Bridge.

1

Create a GitHub fine-grained token

Vercel needs permission to write the synced data files to your repo.

  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: MILO Sync
  3. Expiration: pick whatever (12 months is fine)
  4. Resource owner: marinlazic
  5. Repository access: Only select repositories → choose marinlazic/MILO
  6. Repository permissions → Contents: Read and write
  7. Click Generate token, then copy the token (starts with github_pat_…) — you'll only see it once
2

Add two environment variables to Vercel

Go to vercel.com/dashboard → your MILO project → Settings → Environment Variables. Add both:

  • GITHUB_TOKEN = the token from Step 1
  • SYNC_SECRET = any long random string (this authenticates the bookmarklet — generate one below)

Apply to all 3 environments (Production / Preview / Development). Then redeploy (Deployments → latest → ⋯ → Redeploy).

3

Install the MILO Sync Chrome extension

Why an extension and not a bookmarklet? Bridge's Content Security Policy blocks bookmarklets from contacting external sites. Chrome extensions get explicit cross-origin permission, which bypasses CSP cleanly.
  1. Download or clone this repo, OR open the extension/ folder in github.com/marinlazic/MILO/extension
  2. If you're on your Mac: the folder is at ~/Documents/GitHub/MILO/extension
  3. Open Chrome → navigate to chrome://extensions
  4. Toggle Developer mode ON (top right of that page)
  5. Click Load unpacked → select the extension/ folder
  6. The MILO Sync icon appears in your extensions list. Pin it to the toolbar: click the puzzle-piece icon → click the pin next to "MILO Sync"
4

Use it daily

  1. Open Bridge Athletic and log in (bridgeathletic.com)
  2. Click the MILO Sync icon in your Chrome toolbar
  3. First time only: paste your SYNC_SECRET in the popup (it saves locally — you only do this once per device)
  4. Click Sync now
  5. ~30-60s later: ✓ Synced. ~60-90s after that, milo-cyan.vercel.app shows fresh data.
