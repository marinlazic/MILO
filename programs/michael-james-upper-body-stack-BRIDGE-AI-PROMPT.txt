· 40 minutes maximum per session
· Each session includes 2 warm-up sets at the start
· Working rep range: 8-12 for all hypertrophy work (NOT EMOM, NOT density,

  DO NOT include any lower-body exercises in this program

═══════════════════════════════════════════════════════════════════════════════
THE THREE WORKOUTS
═══════════════════════════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────────────────────────
WORKOUT A · PUSH DAY (Chest + Triceps + Front/Side Delts) — 40 min
──────────────────────────────────────────────────────────────────────────────

WARM-UP (~5 min, 2 light sets total):
  · Set 1: Push-Up × 10 reps (bodyweight)
  · Set 2: Barbell Bench Press × 8 reps @ 50% Difficulty

WORKING SETS:

  1. Barbell Bench Press
     4 sets × 8 reps @ 75% Difficulty · Rest 90 sec between sets

  2. Incline Dumbbell Bench Press
     3 sets × 10 reps @ 72% Difficulty · Rest 75 sec

  3. Cable Chest Fly (high to low OR mid)
     3 sets × 12 reps @ 70% Difficulty · Rest 60 sec

  4. Triceps Rope Pushdown
     3 sets × 12 reps @ 70% Difficulty · Rest 60 sec

  5. EZ-Bar Skullcrusher
     3 sets × 10 reps @ 72% Difficulty · Rest 60 sec

──────────────────────────────────────────────────────────────────────────────
WORKOUT B · PULL DAY (Back + Biceps + Rear Delts) — 40 min
──────────────────────────────────────────────────────────────────────────────

WARM-UP (~5 min, 2 light sets total):
  · Set 1: Band Pull-Apart × 15 reps
  · Set 2: Lat Pulldown × 8 reps @ 50% Difficulty

WORKING SETS:

  1. Pull-Up (or Lat Pulldown if unable to do 8 bodyweight)
     4 sets × 8 reps @ 75% Difficulty · Rest 90 sec

  2. Barbell Bent-Over Row
     4 sets × 10 reps @ 75% Difficulty · Rest 75 sec

  3. Seated Cable Row
     3 sets × 12 reps @ 72% Difficulty · Rest 60 sec

  4. Dumbbell Bicep Curl
     3 sets × 10 reps @ 75% Difficulty · Rest 60 sec

  5. Hammer Curl (dumbbell)
     3 sets × 12 reps @ 72% Difficulty · Rest 45 sec

──────────────────────────────────────────────────────────────────────────────
WORKOUT C · ARMS + SHOULDERS DAY (specialization for arm growth) — 40 min
──────────────────────────────────────────────────────────────────────────────

WARM-UP (~5 min, 2 light sets total):
  · Set 1: Band Pull-Apart × 15 reps
  · Set 2: Seated Dumbbell Shoulder Press × 8 reps @ 50% Difficulty

WORKING SETS:

  1. Seated Dumbbell Shoulder Press
     4 sets × 10 reps @ 75% Difficulty · Rest 90 sec

  2. Dumbbell Lateral Raise
     3 sets × 12 reps @ 70% Difficulty · Rest 60 sec

  3. SUPERSET (back-to-back, no rest within):
     3a. EZ-Bar Bicep Curl — 10 reps @ 75% Difficulty
     3b. EZ-Bar Skullcrusher — 10 reps @ 75% Difficulty
     3 supersets total · Rest 75 sec between supersets

  4. SUPERSET:
     4a. Hammer Curl — 12 reps @ 72% Difficulty
     4b. Cable Triceps Pushdown — 12 reps @ 72% Difficulty
     3 supersets total · Rest 60 sec between supersets

  5. Cable Face Pull (finisher for rear delts + upper back)
     2 sets × 15 reps @ 65% Difficulty · Rest 45 sec

12-WEEK PROGRESSION MAP
═══════════════════════════════════════════════════════════════════════════════

The three workouts above are the TEMPLATE. Loads and minor variations evolve
across 12 weeks in three 4-week mesocycles:

──────────────────────────────────────────────────────────────────────────────
BLOCK 1 — FOUNDATION (Weeks 1-4) · Build the habit, dial in form
──────────────────────────────────────────────────────────────────────────────

W1 (RE-ENTRY week — MJ has been off 6 weeks):
  · Drop primary load to 70% Difficulty (instead of 75% in template)
  · Drop secondary to 68%
  · 3 sets instead of 4 on the heaviest exercise of each session
  · Goal: re-establish movement quality, no soreness

W2: Template loads (Push primary 75% · Pull primary 75% · OHP 75%)

W3: +2.5% Difficulty on all primary lifts (so 77.5%)

W4 (DELOAD): Reduce all sets by 1 (so 3 sets becomes 2, 4 becomes 3).
  All loads at 60% Difficulty. Same exercises, same exercise order, just
  lower volume + lower intensity. Use the week to recover.

──────────────────────────────────────────────────────────────────────────────
BLOCK 2 — VOLUME BUMP (Weeks 5-8) · Add sets, introduce drop sets
──────────────────────────────────────────────────────────────────────────────

W5: Add 1 set to every exercise (so 4 sets becomes 5, 3 becomes 4)
  Loads: primary 75% · secondary 72%

W6: Same volume as W5. Add a DROP SET on the LAST exercise of each session:
  · Workout A: Final set of EZ-Bar Skullcrusher → after reaching failure,
    drop weight 30% and immediately rep to failure (no rest)
  · Workout B: Final set of Hammer Curl → same drop set protocol
  · Workout C: Final set of Cable Face Pull → same drop set protocol

W7: Same as W6 but ADD ANOTHER DROP SET on the second-to-last exercise.
  Loads: primary 78% · secondary 75%

W8 (DELOAD): Back to template volume (W2 numbers), 60% Difficulty, no drop sets.

──────────────────────────────────────────────────────────────────────────────
BLOCK 3 — INTENSIFICATION (Weeks 9-12) · Exercise variation, heavier loads
──────────────────────────────────────────────────────────────────────────────

For Block 3, ROTATE exercises slightly to introduce variation. Keep the
same set/rep schemes as Block 2 (5 sets primary, 4 sets secondary, etc.).

W9-11 EXERCISE SWAPS:
  Workout A · PUSH:
    · Swap Barbell Bench Press → Dumbbell Bench Press (heavier stimulus,
      different shoulder angle for hypertrophy)
    · Swap Cable Chest Fly → Dumbbell Chest Fly on flat bench
    · Swap Triceps Rope Pushdown → Overhead Cable Rope Triceps Extension

  Workout B · PULL:
    · Swap Pull-Up → Weighted Pull-Up (add small belt load) OR continue
      with Lat Pulldown but heavier
    · Swap Seated Cable Row → Single-Arm Dumbbell Row
    · Swap Dumbbell Bicep Curl → Preacher Curl

  Workout C · ARMS + SHOULDERS:
    · Swap Seated Dumbbell Shoulder Press → Standing Barbell Overhead Press
    · Swap Dumbbell Lateral Raise → Cable Lateral Raise
    · Keep the supersets — same structure, same exercises

LOAD PROGRESSION:
  W9: Primary 78% · Secondary 75% · 4 sets primary, 3 sets secondary
  W10: Primary 80% · Secondary 78% · same volume
  W11: Primary 82% · Secondary 80% · same volume
       (heaviest hypertrophy loads of the block)
  W12: Optional measurement re-test week (see below) — light volume.

W12 (BODY COMP RE-MEASUREMENT WEEK):
  This is NOT a 1RM test week (this is a hypertrophy program, not strength).
  Goal: measure arm circumference, chest, weight, and visible muscle gain.
  All three workouts run at W4 deload volume (3 sets primary, 2 sets
  secondary, 60% Difficulty). Take photos and tape measurements at the
  start of the week.

═══════════════════════════════════════════════════════════════════════════════
INTENSITY KEY (%Difficulty)
═══════════════════════════════════════════════════════════════════════════════

  82% = heavy hypertrophy / last 2 reps challenging
  78% = moderate-heavy working / last 3 reps challenging
  75% = typical working hypertrophy intensity (10 reps with 2 in tank)
  72% = moderate (12 reps comfortable, 13th would be a grind)
  70% = light working / drop-set bottom-out
  65% = light isolation
  60% = deload week working intensity
  50% = warm-up set load
