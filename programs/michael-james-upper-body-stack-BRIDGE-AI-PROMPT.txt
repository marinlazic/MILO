Build a 12-week upper-body strength program for Michael James (48 y/o, 97 kg)
called "Upper Body Stack". Format the program as a PLAYLIST. Prescribe all
loads in %Difficulty (NOT %1RM, NOT RPE, NOT RIR). Make every workout's
structure crystal clear: name each block, label set types (EMOM, Superset,
Triset, Straight Sets, AMRAP, Wave Loading, Test Set), and specify exact
rest times for every block. No "rest as needed" placeholders except where
explicitly noted for grip work.

PROGRAM PARAMETERS
- 3 upper-body sessions per week (A · Bench, B · Pull, C · Overhead)
- Athlete runs 2 self-managed lower-body sessions per week separately — do
  not include any main lower-body work in this program
- No warmups prescribed — athlete handles his own mobility and tissue work
- Accessory lower body (calves, tibialis, glutes) woven into the EMOM pair
  exercises so it's covered without adding standalone LB blocks
- Integrated core + power threaded through every session (band rotations,
  ViPR-style stepping moves, med ball, KB bottoms-up, wall T-mob, Pallof)
- 12 weeks structured as 3 × 4-week mesocycles with deload at W4 + W8 and
  a taper + retest in W12

DENSE TRAINING FORMAT (athlete's preferred style)
Use EMOM (Every Minute On the Minute) for almost every loaded block:
- 20D3 = 20 sets x 3 reps on the minute
- 20D2 = 20 sets x 2 reps on the minute
- 15D2 = 15 sets x 2 reps on the minute (peak block)
- 10D5 = 10 sets x 5 reps on the minute
- 10D3 = 10 sets x 3 reps on the minute (deload weeks)
- 8D3, 6D3 = used in peak block for low-rep heavy work
- 5D10 = 5 sets x 10 reps on the minute (tertiary blocks)

Within each EMOM block, pair the primary lift with a complementary exercise
that rotates every 4 rounds in the 20-round blocks (so 5 different pairing
movements across 20 rounds: rounds 1-4, 5-8, 9-12, 13-16, 17-20).

MESOCYCLE STRUCTURE
═════════════════════════════════════════════════════════════════════════════

BLOCK 1 — FOUNDATION (Weeks 1-4)
Goal: Re-establish work capacity. Build the dense rhythm. Find baseline loads.

Workout A · Dense Bench:
- Block 1: 20D3 Barbell Bench Press EMOM × Superset, paired with band
  anti-rotation press / KB half-kneeling bottoms-up press / single-leg
  calf raise / band pull-apart / no-pair-bar-speed-focus rotated every
  4 rounds
- Block 2: 10D5 DB Lateral Raise (3-sec lowering tempo) EMOM × Superset,
  paired with med ball rotational slam (rounds 1-5) and tibialis raise
  (rounds 6-10)
- Block 3: 5D10 Cable Triceps Pushdown EMOM × Superset with Pallof Press
  15-sec hold each side
- Block 4: Grip Finisher — 3 sets x 20 reps Behind-the-Back Barbell
  Wrist Curl, rest 60 sec between sets

Workout B · Dense Pull:
- Block 1: 20D2 Chin-Up (bodyweight) EMOM × Superset, paired with
  ground-to-stand drill / band Y's / wall T-mob rotational reach / loaded
  double-leg calf raise / no-pair rotated every 4 rounds
- Block 2: 10D5 Barbell Bent-Over Row EMOM × Superset, paired with banded
  rotational wood chop (rounds 1-5) and bumper plate pinch hold (rounds 6-10)
- Block 3: 5D10 Heavy DB Hammer Curl EMOM × Superset with Glute Bridge 12 reps
- Block 4: Grip Finisher — 4 sets x 15-20 sec Bumper Plate Pinches, rest 45 sec

Workout C · Dense Overhead:
- Block 1: 20D3 Standing BB Overhead Press EMOM × Superset, paired with
  ViPR Shlift Lateral Step / ViPR Uppercut Back Step / ViPR Trans Step
  with Up Shlift / wall T-mob rotational reach / no-pair rotated every
  4 rounds. If no ViPR available, substitute: KB Side-Step Press /
  Reverse Lunge with Single-Arm DB Press / KB Lateral Lunge with
  Pass-Through (one per missing ViPR slot)
- Block 2: 10D5 Close-Grip Bench Press (3 sec down / 3 sec up tempo)
  EMOM × Superset, paired with tempo close-grip pushup (rounds 1-5) and
  anti-extension plank reach (rounds 6-10)
- Block 3: 5D10 EZ-Bar Skullcrusher EMOM × Superset with KB Bottoms-Up
  Carry 20 metres
- Block 4: Grip Finisher — 4 sets x 25 metres DB or KB Farmers Carry, rest 60 sec

LOAD PROGRESSION (Block 1):
  W1: Primary lifts 70% Difficulty · Secondary 75% Difficulty · Tertiary 75%
  W2: Primary 72% · Secondary 78% · Tertiary same load +1 rep per set
  W3: Primary 75% · Secondary 82% · Tertiary +1 more rep per set
  W4 DELOAD: cut all volumes in half (20D3 becomes 10D3, 10D5 becomes 5D5,
             5D10 becomes 3D10). All loads 60% Difficulty.
             Replace grip finishers with mobility finishers
             (Pallof, T-spine open book, band pull-apart).

BLOCK 2 — STRENGTH (Weeks 5-8)
Goal: Heavier loads. Exercise variation. Push density.

Workout A · Strength Bench (same dense format, varied exercises):
- Block 1: 20D3 BB Bench Press EMOM × Superset, with NEW pairings —
  standing cable anti-rotation press / standing KB bottoms-up press /
  loaded double-leg calf raise / face pull / no-pair rotated every 4 rounds
- Block 2: 10D5 DB Bench Press EMOM × Superset (replaces lateral raise,
  heavier), with med ball slam and tibialis raise
- Block 3: 5D10 Cable Rope Triceps Extension (overhead) with Pallof Press
- Block 4: 3 sets x 25 reps Behind-the-Back Wrist Curl, 60 sec rest

Workout B · Strength Pull:
- Block 1: 20D2 Weighted Chin-Up (introduce BW + load) EMOM × Superset,
  with NEW pairings — half-kneeling-to-standing / band W's / open books /
  loaded calf raise / no-pair
- Block 2: 10D5 Pendlay Row (BB dead-stop) EMOM × Superset with banded
  wood chop and heavy bumper plate pinch
- Block 3: 5D10 DB Concentration Curl with Single-Leg Glute Bridge
- Block 4: 4 sets x 20-25 sec Bumper Plate Pinches, 45 sec rest

Workout C · Strength Overhead:
- Block 1: 20D3 Push Press (leg drive permits heavier load — load is %
  Difficulty of the strict OHP 3RM) EMOM × Superset, with KB Side-Step
  Press / Reverse Lunge w Single-Arm DB Press / KB Lateral Lunge with
  Pass-Through / Tall Kneeling Anti-Rotation Press / no-pair rotated
- Block 2: 10D5 Spoto Press (bench pause 1cm off chest) EMOM × Superset
  with tempo close-grip pushup and side plank with hip drop
- Block 3: 5D10 Lying DB Triceps Extension with KB Bottoms-Up Carry 20m
- Block 4: 4 sets x 30 metres DB or KB Farmers Carry (heavier), 60 sec

LOAD PROGRESSION (Block 2):
  W5: Primary 75% Difficulty · Secondary 82% · Tertiary 78%
  W6: Primary 78% · Secondary 85% · Tertiary +1 rep per set
  W7: Primary 80% · Secondary 88% · Tertiary +1 more rep per set
      ADD optional 3RM Bench retest at START of Workout A (W7) —
      ramp 5 @ 55%, 5 @ 70%, 3 @ 82%, 3 @ 92-100% (true 3RM). If PR,
      update working loads for W8-W12 by +5%.
  W8 DELOAD: cut volumes in half. Primary load 65% Difficulty.
             Drop weighted chin-up back to bodyweight.
             Mobility finishers replace grip work.

BLOCK 3 — PEAK + RETEST (Weeks 9-12)
Goal: Lower reps, heavier loads, wave loading, retest at W12.

Workout A · Peak Bench:
- Block 1 (W9): 15D2 BB Bench Press EMOM × Superset at 82% Difficulty
  (lower rep density, heavier loads), pairs as W1-3 but reduced reps
- Block 1 (W10-W11): Switch to WAVE LOADING — 6 working sets with 2-3
  min rest, NOT EMOM. W10 wave: 3@75% / 2@82% / 1@88% / 3@78% / 2@85% /
  1@90%. W11 wave (heavier): 2@82% / 1@88% / 1@92% / 2@85% / 1@90% / 1@94%
- Block 2: 8D3 Floor Press (BB) EMOM × Superset, paired with heavy med
  ball slam and heavy single-leg calf raise
- Block 3: 5D10 (or 5D8 in W11) Heavy DB Skullcrusher with Pallof Press
- Block 4: 3 sets x 18-20 reps Behind-the-Back Wrist Curl heavy, 75-90 sec rest

Workout B · Peak Pull:
- Block 1: 15D2 (W9-W10) / 10D2 (W11) Slow Strict Pause Chin-Up at
  BW + 5/7.5/10 kg progression. Tempo: 2 up / 2 pause at top / 3 lower /
  1 pause at bottom. Pairs as Block 2 with reduced rep counts in W11.
- Block 2: 8D3 (W9-W10) / 6D3 (W11) Heavy Pendlay Row at 88-92% Difficulty
  paired with banded wood chop and heavy bumper plate pinch
- Block 3: 5D8 (or 5D6 in W11) Cheat Curl heavy with Single-Leg Glute Bridge
- Block 4: 3-4 sets x 25-30 sec Heavy Bumper Plate Pinches, 60-75 sec rest

Workout C · Peak Overhead:
- Block 1 (W9): 15D2 Standing BB OHP STRICT at 82% Difficulty
- Block 1 (W10-W11): WAVE LOADING (same scheme as bench wave) on strict OHP
- Block 2: 8D3 (W9-W10) / 6D3 (W11) Strict Close-Grip Bench Press at
  88-92% Difficulty paired with tempo close-grip pushup and anti-extension
  plank reach
- Block 3: 5D8 (or 5D6 in W11) Tate Press with KB Bottoms-Up Carry 20m
- Block 4: 4 sets x 30 metres DB or KB Farmers Carry HEAVY, 75-90 sec rest

LOAD PROGRESSION (Block 3):
  W9:  Primary 82% Difficulty · Secondary 88% · Tertiary 82%
  W10: Wave loading on primary lifts (Bench + OHP) · Secondary 90% · Tertiary 85%
  W11: Heavier wave on primary lifts (peak intensities to 94% Difficulty)
       Secondary 92% · Tertiary 88%
  W12 TAPER + RETEST:
    Day 1 — Taper Bench: STRAIGHT SETS short ramp 5@55% / 3@70% / 1@80% /
            1@85%, done. ~20 min, no fatigue, no accessories. Neural primer only.
    Day 3 — Test Chin & Row:
            Block 1: AMRAP Strict Chin-Up bodyweight (max unbroken reps,
            record reps)
            Block 2: TEST SET BB Bent-Over Row 3RM ramp (5@55% / 5@70% /
            3@82% / 3@92-100% record load)
    Day 5 — Test Bench & OHP:
            Block 1: TEST SET BB Bench Press 1RM attempt (5@55% / 3@70% /
            1@85% / 1@92% / 1@100% — optional 1@102-105% if clean)
            Block 2: TEST SET Standing BB OHP 1RM attempt (5@55% / 3@70% /
            1@88% / 1@95% / 1@100%)

Create a separate workout at the start of the playlist titled

INTENSITY KEY (%Difficulty — relative intensity)
  100% Difficulty = max effort, true 1RM territory
   92% Difficulty = near-maximal, 1 rep left in tank
   85% Difficulty = heavy working / 2 reps left
   78% Difficulty = moderate-heavy / 3 reps left
   75% Difficulty = typical working intensity
   70% Difficulty = typical first-set load on dense work
   60% Difficulty = deload week working intensity
   55% Difficulty = warmup / activation
