PART 2 · MASTER PROGRAM DESCRIPTION (paste into Bridge as program notes)
═══════════════════════════════════════════════════════════════════════════════

Upper Body Stack — 12-week dense-training block for Michael James (48, 97 kg).
Built around his preferred NDM format (N sets x M reps on the minute) and
inspired by the Benchuary 2026 PPSA bench-peaking template, restructured into
three 4-week mesocycles with built-in deloads at W4 and W8 and a peak + retest
at W12.

PROGRAM ARCHITECTURE
  · 3 upper-body sessions per week (A · Bench, B · Pull, C · Overhead)
  · Athlete runs 2 self-managed lower-body sessions per week separately
  · No warmups prescribed — athlete runs his own mobility + tissue work
  · Accessory lower body (calves, tibs, glutes) woven into EMOM pairs
  · Power + integrated core (band rotations, ViPR, med ball, KB bottoms-up,
    wall T-mob) threaded through every session

MESOCYCLE PROGRESSION
  Block 1 (W1-4)  FOUNDATION   Re-establish work capacity, find dense rhythm
  Block 2 (W5-8)  STRENGTH     Heavier loads, exercise variation, density push
  Block 3 (W9-12) PEAK + TEST  Wave loading, lower reps, retest at W12

PROGRESSIVE OVERLOAD (% Difficulty)
  · Primary dense (20D3/20D2): W1 70% → W3 75% → W7 82% → W11 88%
  · Secondary EMOM (10D5):     W1 75% → W3 82% → W7 88% → W11 92%
  · Tertiary EMOM (5D10):      same load, +1 rep per set per week if clean
  · Deloads at W4 and W8 cut primary volume in half and pull intensity to ~60%

EXERCISE VARIETY (deliberately rotated per mesocycle)
  Block 1: BB Bench / Chin-Up / BB OHP   (foundation movements)
  Block 2: DB Bench / Weighted Chin-Up / Push Press  (variation + load)
  Block 3: BB Bench (wave) / Slow Strict Pause Chin / BB OHP (wave)  (peak)
  Pairings, accessory LB, and core/power moves rotate within each block to
  preserve groove while maintaining variety MJ specifically requested.

TESTING POINTS
  · Baseline (W1 Workout 1):       3RM Bench, 3RM OHP, max strict Chin-Up
  · Mid-block check (W7 Workout 21): Optional 3RM Bench retest
  · Final retest (W12 Workouts 36-37): 1RM Bench, 1RM OHP, max Chin-Up
  Expected delta over 12 weeks: Bench +10-15 kg · OHP +5-7.5 kg · Chin-Up +3-5 reps

▶ INTENSITY KEY (%Difficulty — relative intensity)

  100% Difficulty  Max effort, true 1RM territory
   92% Difficulty  Could grind 1 more rep — near-maximal
   88% Difficulty  Heavy working / 2 reps left
   85% Difficulty  Working heavy
   82% Difficulty  Heavy working weight / 2-3 reps left
   78% Difficulty  Moderately heavy / 3 reps left
   75% Difficulty  Typical working intensity / 3 reps left
   70% Difficulty  Typical first-set load on dense work / 4 reps left
   65% Difficulty  Moderate / 5 reps left
   60% Difficulty  Deload week working intensity
   55% Difficulty  Warmup / activation

▶ SET-TYPE VOCABULARY USED THROUGHOUT

  EMOM        Every Minute On the Minute — perform prescribed reps in the
              first part of each minute, rest the remainder.
  Superset    Two exercises back-to-back, no rest. Labelled 1a / 1b.
  Triset      Three exercises back-to-back. Labelled 1a / 1b / 1c.
  Straight    Single exercise, all sets in one block, set rest in between.
  AMRAP       As Many Reps As Possible — single set to technical failure.
  Test set    Ramped single-set work to a true max.
  Wave        Reps descend within a wave, second wave heavier. Labelled below.

PART 6 · ATHLETE-FACING NOTES FOR MJ
═══════════════════════════════════════════════════════════════════════════════

THE PROGRAM IN ONE PARAGRAPH
  Three upper-body sessions per week (A · Bench, B · Pull, C · Overhead) for
  12 weeks. Your two lower-body sessions slot in between. Three phases:
  Foundation (W1-4) builds the dense rhythm and re-establishes baseline.
  Strength (W5-8) introduces exercise variety and heavier loads. Peak (W9-12)
  shifts to wave loading and lower reps, ending in a retest of your 1RM
  Bench, OHP, and max chin-ups.

HOW TO RUN IT
  · This is a playlist, not a calendar. Run the workouts in order at your pace.
  · No warmups prescribed — keep doing your own mobility + tissue work.
    The first 2-3 sets of each EMOM are your specific warmup; ramp load up
    to working %Difficulty in those rounds.
  · EMOM pairings are MANDATORY, not optional. They're the second half of
    each minute. Skipping them turns the program into something it isn't.
  · If a rep slows down or grinds, drop the load 2.5-5 kg for the next round
    and hold. Density is quality reps under fatigue, not grinding singles.
  · Calves, tibialis, glutes are woven into the EMOM pairs — no extra LB
    accessory needed on these days.
  · Grip finishers at the end of every dense session. Keep them.
  · Log your working weight per dense block in Bridge so MILO can track
    your e1RM trends across the block.

WHAT TO LOOK FOR EACH WEEK
  · W1-3: Each week loads nudge up 2-3%. Bar speed is your metric — if every
          rep is fast and clean, you're in the right load range.
  · W4: DELOAD. Half the volume, low intensity. Don't try to "make up" the
        deload by adding weight — the recovery IS the work.
  · W5-7: New exercise variations (DB Bench, Weighted Chin-Up, Push Press).
          Expect 1-2 sessions to find the right load. Loads then nudge up.
  · W7 has an optional 3RM Bench retest at the start. If you hit a PR there,
          update working loads for the rest of the block by +5%.
  · W8: DELOAD again. Same rules.
  · W9-11: Peak. Lower reps, heavier loads, wave loading appears. This is
          where the strength shows up.
  · W12: Test week. Day 1 is JUST a neural primer (do not turn it into a
          workout). Day 3 = chin-up + row test. Day 5 = bench + OHP 1RM.
