PART 2 · PROGRAM-LEVEL DESCRIPTION (paste this into Bridge as program notes)
═══════════════════════════════════════════════════════════════════════════════

Upper Body Stack — 4-week dense-training block for Michael James.
3 upper-body sessions per week (A=Bench, B=Pull, C=Overhead) run as a
playlist. Michael runs 2 self-managed lower-body sessions per week
between these. No warmups prescribed — Michael runs his own mobility
and tissue work. Accessory lower-body work (calves, tibs, glutes) is
woven into the EMOM pairs so he doesn't need extra LB on these days.
Power and integrated core (band rotations, ViPR, med ball, KB bottoms-up,
wall T-mob) thread through every session.

Format: EMOM (Every Minute On the Minute) × Superset throughout.
Primary block: 20 sets x 3 reps on the minute, paired in 5 blocks of 4.
Secondary block: 10 sets x 5 reps on the minute, paired in 2 blocks of 5.
Tertiary block: 5 sets x 10 reps on the minute, single-pair throughout.
Grip finisher: straight sets, rest as needed.

Progressive overload (RIR):
  Primary dense:    W1 4 RIR → W2 3-4 RIR → W3 3 RIR → W4 test
  Secondary EMOM:   W1 3 RIR → W2 2 RIR → W3 2 RIR → W4 deload
  Tertiary EMOM:    +1 rep per set per week (same load) if previous week clean
Baseline test in Week 1 Workout 1; retest in Week 4 Workouts 12-13.
Expected delta: Bench +5-7 kg, OHP +2.5-5 kg, Chin-Up +1-2 unbroken reps.

═══ WORKOUT 1 · UPPER BODY STACK · BASELINE TEST ═══════════════════════════════

Purpose: Record baseline 3RM Bench, 3RM Overhead Press, max strict Chin-Up.
Total time: ~30-35 minutes.
Format: Straight sets (NOT dense, NOT EMOM). Test ramps.

▼ BLOCK 1 · TEST SET · BARBELL BENCH PRESS — 3 REP MAX RAMP
  Set 1: 5 reps @ 6 RIR · Rest 2 min
  Set 2: 5 reps @ 4 RIR · Rest 2 min
  Set 3: 3 reps @ 3 RIR · Rest 3 min
  Set 4: 3 reps @ 2 RIR · Rest 3 min
  Set 5: 3 reps @ 0-1 RIR (true 3RM) · Rest 4 min
  Notes: Record the load of Set 5 — this is "Bench 3RM" for the block.

▼ BLOCK 2 · TEST SET · STANDING BARBELL OVERHEAD PRESS — 3 REP MAX RAMP
  Set 1: 5 reps @ 6 RIR · Rest 2 min
  Set 2: 5 reps @ 4 RIR · Rest 2 min
  Set 3: 3 reps @ 2 RIR · Rest 3 min
  Set 4: 3 reps @ 0-1 RIR (true 3RM) · Rest 3 min
  Notes: No leg drive, full lockout at top. Record Set 4 load as "OHP 3RM".

▼ BLOCK 3 · AMRAP · CHIN-UP — MAX STRICT REPS
  1 set, bodyweight, full ROM, unbroken until failure.
  Notes: Record total reps as "Chin-Up max". Strict — no kip, no momentum.


═══ WORKOUT 2 · UPPER BODY STACK · A · DENSE BENCH (W1) ═════════════════════════

Purpose: Week 1 of the dense bench block. Establish working loads and rhythm.
Total time: ~50 minutes.
Format: EMOM × Superset throughout.

▼ BLOCK 1 · EMOM × SUPERSET · 20 ROUNDS · 1 MINUTE PER ROUND
  Round 1-4:
    1a. Barbell Bench Press — 3 reps @ first-set 4 RIR
    1b. Standing Band Anti-Rotation Press — 6 reps each side
  Round 5-8:
    1a. Barbell Bench Press — 3 reps (same load)
    1b. KB Half-Kneeling Bottoms-Up Press — 5 reps each side
  Round 9-12:
    1a. Barbell Bench Press — 3 reps (same load)
    1b. Loaded Single-Leg Calf Raise — 12 reps each side
  Round 13-16:
    1a. Barbell Bench Press — 3 reps (same load)
    1b. Band Pull-Apart — 12 reps
  Round 17-20:
    1a. Barbell Bench Press — 3 reps (same load, no pair, focus on bar speed)
  Rest: any remainder of each minute. If bench bar speed slows, drop load
        2.5-5 kg for the next round and hold.

▼ BLOCK 2 · EMOM × SUPERSET · 10 ROUNDS · 1 MINUTE PER ROUND
  Round 1-5:
    2a. DB Lateral Raise (tempo: 3-sec lowering) — 5 reps @ 3 RIR
    2b. Med Ball Rotational Slam — 4 reps each side
  Round 6-10:
    2a. DB Lateral Raise (tempo: 3-sec lowering) — 5 reps (same load)
    2b. Tibialis Raise — 10 reps

▼ BLOCK 3 · EMOM × SUPERSET · 5 ROUNDS · 1 MINUTE PER ROUND
  Round 1-5:
    3a. Cable Triceps Pushdown — 10 reps @ 3 RIR
    3b. Pallof Press — 15-second hold each side

▼ BLOCK 4 · STRAIGHT SETS · GRIP FINISHER
  Behind-the-Back Barbell Wrist Curl — 3 sets x 20 reps · Rest as needed.

PART 5 · NOTES FOR MICHAEL (athlete-facing — share with him)
═══════════════════════════════════════════════════════════════════════════════

· Pace yourself in the playlist. Aim for 3 upper-body sessions per week
  (A → B → C in order). Your two lower-body sessions slot between these.
· No warmups prescribed — keep doing your own mobility, tissue work,
  and (when home) ball juggling / catching / throwing in your warmup.
· EMOM pairings are MANDATORY, not optional. They are the second half
  of each minute and what makes this dense.
· If a rep slows down on a primary lift, drop the load 2.5-5 kg for the
  next set and hold there. Density is quality reps under fatigue.
· Calves, tibialis, glutes are woven INTO the EMOM pairs. You don't
  need to do extra accessory lower body on these days.
· Grip finishers at the end of every session. Keep them in — they're
  the difference between strong wrists and a tweaky elbow.
· Log your working weight per dense block in Bridge so we can track
  e1RM trends week by week.
