═══════════════════════════════════════════════════════════════════════════════
PROGRAM PARAMETERS
═══════════════════════════════════════════════════════════════════════════════

· 4 sessions per week, ~45 min each
· DUP layout — each week cycles through 4 stimuli:
    Day 1 · Lower STRENGTH   (heavy, 5-6 reps)
    Day 2 · Upper STRENGTH   (heavy, 5-6 reps)
    Day 3 · Lower HYPERTROPHY + POWER  (moderate-high reps, plyos)
    Day 4 · Upper HYPERTROPHY (moderate-high reps, volume)
· Every session opens with breath + movement prep + activation (~8 min)
· Working rep range adapted per day type (see scheme below)
· Use Alana's existing exercise library where possible (KB, DB, TRX, med ball)
· Use ONLY Bridge library exercises with video demos — no custom moves

═══════════════════════════════════════════════════════════════════════════════
DUP REP SCHEME (the periodization engine)
═══════════════════════════════════════════════════════════════════════════════

  STRENGTH DAYS (Day 1, Day 2):
    Primary lift:    4-5 sets × 5-6 reps @ 78-82% Difficulty · Rest 2 min
    Secondary lift:  4 sets × 6-8 reps @ 75-78% Difficulty · Rest 90 sec
    Accessory:       3 sets × 8 reps @ 70% Difficulty · Rest 60 sec

  HYPERTROPHY DAYS (Day 3, Day 4):
    Primary lift:    4 sets × 8-10 reps @ 72-75% Difficulty · Rest 75 sec
    Secondary lift:  3-4 sets × 10-12 reps @ 70-72% Difficulty · Rest 60 sec
    Accessory:       3 sets × 12-15 reps @ 65-68% Difficulty · Rest 45 sec

  POWER element (Day 3 only — built into Lower Hypertrophy session):
    Plyometrics:     3-4 sets × 4-6 reps explosive · Rest 60 sec (full recovery)

═══════════════════════════════════════════════════════════════════════════════
4-WEEK PROGRESSIVE OVERLOAD MAP
═══════════════════════════════════════════════════════════════════════════════

Same exercises, same DUP structure across all 4 weeks. The variables that
change week-to-week are load (%Difficulty) and total volume.

────────────────────────────────────────────────────────────────────────────────
WEEK 1 — ESTABLISH BASELINE (template loads above)
────────────────────────────────────────────────────────────────────────────────
  Strength days (1,2): primary 80% · secondary 78% · accessory 72%
  Hypertrophy days (3,4): primary 75% · secondary 72% · accessory 68%
  Goal: find the load that matches each %Difficulty — record working weight.

────────────────────────────────────────────────────────────────────────────────
WEEK 2 — INTENSITY NUDGE
────────────────────────────────────────────────────────────────────────────────
  Strength days: primary 82% · secondary 80% · accessory 75%
  Hypertrophy days: primary 78% · secondary 75% · accessory 70%
  Sets/reps: identical to W1. Only the load creeps up.
  Goal: same exercises, slightly harder. Same number of reps clean.

────────────────────────────────────────────────────────────────────────────────
WEEK 3 — VOLUME + INTENSITY PEAK
────────────────────────────────────────────────────────────────────────────────
  Strength days: primary 82% · secondary 80% · accessory 75%
        ADD 1 set to the primary lift (so 5×5 becomes 6×5 on Days 1 + 2)
  Hypertrophy days: primary 80% · secondary 78% · accessory 72%
        ADD 1 set to the primary lift (so 4×10 becomes 5×10 on Days 3 + 4)
  Goal: heaviest week of the block. Last set primary should be ~RPE 8.

────────────────────────────────────────────────────────────────────────────────
WEEK 4 — DELOAD
────────────────────────────────────────────────────────────────────────────────
  All days: primary 65% · secondary 62% · accessory 60% · plyos 50% intensity
  Reduce set count: primary 3 sets (instead of 5 or 4), secondary 3, accessory 2
  Skip supersets — run as straight sets only.
  Skip core finisher OR replace with mobility (Child's Pose, T-spine open book).
  Goal: recover. Pattern grooves stay, fatigue drops to near-zero.
  At the end of W4, retest: log working weight on KB Deadlift and Standing
  KB OHP at 5 reps @ 80% Difficulty — compare to W1 same lift, same %.

═══════════════════════════════════════════════════════════════════════════════
INTENSITY KEY (%Difficulty)
═══════════════════════════════════════════════════════════════════════════════

  82% = heavy working / 2 reps left in tank
  80% = strength working / 2-3 reps left
  78% = moderate-heavy / 3 reps left
  75% = typical hypertrophy intensity (10 reps, 2 in tank)
  72% = moderate hypertrophy
  70% = light working / superset bottom
  68% = isolation
  65% = deload week working intensity
  62% = deload secondary
  60% = deload accessory
  50% = warm-up / activation
